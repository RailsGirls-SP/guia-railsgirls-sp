The Message Board app already does the main things: post, see, fix and delete messages. But it doesn't look like a real message board yet: the messages show up as text, one below the other.

On a real board, each message is a sticky note stuck on the wall.

{: .desafio }
Make each message look like a sticky note, side by side on the board. The change is **only visual**: no stored message changes, and no new information shows up.
