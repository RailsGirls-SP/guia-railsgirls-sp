Imagine that Bia posts a message and closes the browser. The next day, Ana opens the message board: Bia's message needs to be there.

But for that, the message needs to be stored somewhere while nobody is looking. Right now, the Message Board app doesn't have anywhere to store anything.

{: .desafio }
Create a place in the app to store the messages, each with the name of the person who wrote it and the text of the message.
