# Start here

Before starting the project, see what you'll need. It's not much, and you don't need to know anything about programming.

## What you need

![A woman writing by hand on paper, with a computer next to her]({{ '/assets/images/anotando.svg' | relative_url }})
{: .ilustracao .ilustracao-secao }

Illustration: [unDraw](https://undraw.co/)
{: .fs-2 .text-center }

- **A GitHub account.** That's where your project's code will be stored. If you don't have one yet, see [Creating a GitHub account]({{ site.baseurl }}{% link start-here/github-account.md %}).
- **A computer with a browser,** like Chrome, Firefox or Edge. At the workshop, the project runs on **[GitHub Codespaces](https://github.com/features/codespaces)**: a GitHub service that lends you a computer in the cloud, which you use through the browser. That computer already comes with everything the project needs, so you don't install anything.
- **Pen and paper,** to plan before you code.

Want to program on your own computer, without Codespaces? That's in the Extras, for after the workshop: see [Installing on your computer]({{ site.baseurl }}{% link extras/on-your-computer.md %}).
