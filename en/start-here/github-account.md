# Creating a GitHub account

**GitHub** is a website that stores programming projects and lets you work on them from anywhere. To understand better what it is, watch the [introduction to Git and GitHub](https://www.youtube.com/watch?v=UiJ8a8Acvi4) with Rayane Rocha, at Rails Girls São Paulo 2025 (in Portuguese).

## 1. Start signing up

Go to [github.com](https://github.com), type your email in the **Enter your email** field and click **Sign up for GitHub**.

![The GitHub home page with the email field and the Sign up for GitHub button highlighted]({{ '/assets/images/comece-aqui/github-cadastro-email.png' | relative_url }})

## 2. Fill in your details

Choose:

- a password (**Password**);
- a username (**Username**), with no spaces or special symbols. It will show up in the address of your projects;
- your country (**Your Country/Region**).

Then click **Create account**.

![The GitHub sign-up form with the Email, Password, Username and Your Country/Region fields filled in, and the Create account button]({{ '/assets/images/comece-aqui/github-cadastro-formulario.png' | relative_url }})

Sometimes GitHub asks you to solve a puzzle, to confirm you're not a robot. It has a version with images and another with audio (tip: the audio one is usually easier).

## 3. Confirm your email

GitHub sends a code to your email. Type in the code and click **Continue**.

![GitHub's Confirm your email address screen, with eight boxes to type the code and the Continue button]({{ '/assets/images/comece-aqui/github-cadastro-codigo.png' | relative_url }})

## 4. Sign in

After you confirm your email, GitHub shows the sign-in screen. Fill in **Username or email address** with your username or your email, and **Password** with the password you just created. Then click **Sign in**.

![The Sign in to GitHub screen, with the Username or email address and Password fields and the Sign in button]({{ '/assets/images/comece-aqui/github-login.png' | relative_url }})

## 5. Check that everything worked

After signing in, you land on the GitHub dashboard (**Dashboard**). At the top it says **Welcome to GitHub**, followed by your username, and, on the left, **No repositories found**: you don't have any projects yet.

![The GitHub dashboard right after signing in, with the message Welcome to GitHub followed by the username and, on the left, No repositories found]({{ '/assets/images/comece-aqui/github-painel.png' | relative_url }})

That's it, your account is created! For now, you don't need to click anything else on that page: your first repository will be created in the chapter [Where do we start?]({{ site.baseurl }}{% link projects/message-board/01-where-to-start/index.md %}).
