# 03. How do we see all the messages?

Time: about 40 minutes.
{: .fs-5 }

## The challenge

{% include message-board/03/challenge.md %}

## Think before you code

Set aside about 5 minutes. There is no wrong answer.

In this chapter, we're only going to **show** the messages that already exist. Posting a new message is for the next chapter, so you don't need to think about a form right now.

- Go back to the drawing of the main screen you made in [Planning the app]({{ site.baseurl }}{% link projects/message-board/00-planning-the-app.md %}). For now, look only at the cards: what shows up on each one?
- What's the minimum this screen needs to show to already be useful for someone who opens the app? What can wait?
- In what order do the messages show up? Newest first?
- What does the screen show when there aren't any messages yet?

## Compare with our plan

<details markdown="1">
<summary>Open our plan</summary>

At the end of this chapter, anyone who opens the app will see this:

![A page with the title Message Board and, below it, two messages: first "I loved the workshop!", by Bia, and then "My first message!", by Ana]({{ '/assets/images/mural-de-recados/03/resultado-final.png' | relative_url }})
{: .ilustracao }

- **Where it lives:** the message board is the app's main page. Anyone who opens the app's address lands right on it.
- **The order:** the newest messages show up first, like on a social network. That's why Bia, who posted later, shows up at the top.
- **No messages:** instead of an empty page, there's an invitation: "There are no messages yet. How about posting the first one?".
- **The minimum:** each message shows only the text and who wrote it. No colorful cards, no form and no buttons yet: those come in the next chapters.

</details>
