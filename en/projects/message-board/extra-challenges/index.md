# Extra challenges

Finished the project early? Here are some challenges to keep going. Each one starts with the problem, and the hints are hidden: try it on your own first.

## The challenges

The challenges are in order, from easiest to hardest:

1. [Message dates 📅]({{ site.baseurl }}{% link projects/message-board/extra-challenges/message-dates.md %}): each card shows when the message was posted.
2. [Post straight from the message board 📝]({{ site.baseurl }}{% link projects/message-board/extra-challenges/post-from-the-board.md %}): the form sits on the home page, above the cards.
3. [Message colors 🎨]({{ site.baseurl }}{% link projects/message-board/extra-challenges/message-colors.md %}): each person chooses the color of their sticky note.
4. [Filter messages by color 🔎]({{ site.baseurl }}{% link projects/message-board/extra-challenges/filter-by-color.md %}): the message board shows only the messages of one color. This one is just the problem, with no hints.
5. [Likes ❤️]({{ site.baseurl }}{% link projects/message-board/extra-challenges/likes.md %}): each message gets a button to like it.
