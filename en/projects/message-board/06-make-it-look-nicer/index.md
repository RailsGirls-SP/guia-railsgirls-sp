# 06. How do we make the message board look nicer?

Time: about 25 minutes.
{: .fs-5 }

## The challenge

{% include message-board/06/challenge.md %}

## Think before you code

Set aside about 5 minutes. There is no wrong answer.

- Go back to the drawing of the main screen you made in [Planning the app]({{ site.baseurl }}{% link projects/message-board/00-planning-the-app.md %}). What does each message card look like? Where are the text, the author and the buttons?
- How are the cards arranged on the screen: one below the other, or side by side, in a grid?
- And on a phone screen, which is narrower?
- What's the minimum that needs to change for the message board to already look like a message board?

## Compare with our plan

<details markdown="1">
<summary>Open our plan</summary>

At the end of this chapter, anyone who opens the app will see this:

![The message board with the title at the top, the green New message button and, below it, four yellow cards side by side, each with the message, the author in italics and the Edit and Delete buttons]({{ '/assets/images/mural-de-recados/06/mural-post-it.png' | relative_url }})
{: .ilustracao }

- **The cards:** each message becomes a yellow card, like a sticky note, with rounded corners and a little shadow.
- **Inside the card:** the text, the author in italics and, below, the **Edit** and **Delete** buttons, the latter in red.
- **The grid:** the cards sit side by side, four per row. On a phone screen, one fits per row.
- **The New message button:** colorful, highlighted, right below the heading.
- **The form pages:** on New message and Edit message, the form sits in a white box, with the fields neatly arranged and a colorful button.
- **The minimum:** all the cards the same color. Whoever finishes early can let each person choose the color of their message, in the challenge [Message colors]({{ site.baseurl }}{% link projects/message-board/extra-challenges/message-colors.md %}).

</details>
