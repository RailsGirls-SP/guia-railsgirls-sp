# Message Board

In this project, you are going to build a **message board** on the web: an app where anyone can leave a message, which shows up like a sticky note on a wall. You can post, see, fix and delete messages.

![The message board with the title at the top, the green New message button and, below it, four yellow cards side by side, each with the message, the author in italics and the Edit and Delete buttons]({{ '/assets/images/mural-de-recados/06/mural-post-it.png' | relative_url }})
{: .ilustracao }

You don't need to know how to program to get started. The guide explains every step, and by the end of the day you will have built a real app, with [Ruby on Rails]({{ site.baseurl }}{% link glossary.md %}#rails).

## How the project works

The message board grows little by little, one chapter at a time. Each chapter starts with a **problem**, like "how do we post a message?", and always follows the same path:

1. **The challenge:** the problem the chapter solves.
2. **Think before you code:** a few minutes with pen and paper, so you plan before writing code. There is no wrong answer.
3. **Compare with our plan:** what we planned, so you can compare it with yours.
4. **Hands-on:** the steps, one at a time. In each step, you make a guess before running something and check the result afterwards.
5. **What happened?:** an explanation of what you did, questions and answers, a quiz and, if you like, a way to break the app on purpose to learn how to read errors.

Stuck on a step? Every Hands-on page has a **Stuck?** section at the end with the most common problems. And the mentoring team is there to help. 💜

## Everyone at their own pace

You don't need to finish everything today. Everyone goes at a different pace, and that's fine: if you stop halfway, you still leave with a message board that works. The guide stays online after the workshop, and you can keep going at home, from where you stopped.

## Before you start

- **A GitHub account.** If you don't have one yet, see [Creating a GitHub account]({{ site.baseurl }}{% link start-here/github-account.md %}).
- **A browser**, like Chrome, Firefox or Edge. The project runs on **GitHub Codespaces**, a computer in the cloud that already comes with everything installed. Want to use your own computer? That's in the Extras, for after the workshop: see [Installing on your computer]({{ site.baseurl }}{% link extras/on-your-computer.md %}).
- **Pen and paper**, for "Think before you code".

New terms have a link to the [glossary]({{ site.baseurl }}{% link glossary.md %}), with an explanation of each one. You don't need to memorize anything.
