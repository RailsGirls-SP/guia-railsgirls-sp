# Setup

![A monitor with a code editor, a folder window and a terminal open]({{ '/assets/images/ambiente-de-programacao.svg' | relative_url }})
{: .ilustracao .ilustracao-secao }

Illustration: [unDraw](https://undraw.co/)
{: .fs-2 .text-center }

At the workshop, the project runs on **GitHub Codespaces**, and you don't install anything. Codespaces is a computer in the cloud, which you use through the browser, and which already comes with everything the project needs:

- **Ruby**, the language the app's code is written in;
- **Rails**, a set of ready-made tools, made in Ruby, for building websites and apps;
- **Git**, which saves your progress;
- a **code editor**, the program where you write and change the app's files.

Want to know more about each one? See [Ruby, Rails and Git]({{ site.baseurl }}{% link getting-started/ruby-rails-and-git.md %}).

All you need is a GitHub account. If you don't have one yet, see [Creating a GitHub account]({{ site.baseurl }}{% link getting-started/github-account.md %}).

The rest happens in the project itself: in the chapter [Where do we start?]({{ site.baseurl }}{% link projects/message-board/01-where-to-start/index.md %}), you create your repository from a template prepared by Rails Girls SP and open the codespace, with everything already installed.

## Good to know

- **You need internet** the whole time, because the computer is in the cloud.
- **It's free up to a limit of hours per month,** which is enough for the project. To save hours, shut down the codespace when you're done: see how in [All done! What's next?]({{ site.baseurl }}{% link projects/message-board/09-whats-next/index.md %}).
- **Your files stay saved** in the codespace, even when you close the tab. To go back, open the list at [github.com/codespaces](https://github.com/codespaces).

## What about my computer?

You can also program on your own computer, by installing each tool. Since that takes time and varies from computer to computer, it's in the Extras, for after the workshop: see [Installing on your computer]({{ site.baseurl }}{% link extras/on-your-computer.md %}).
