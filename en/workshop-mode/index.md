# Workshop mode

This is the version of the [Message Board]({{ site.baseurl }}{% link projects/message-board/index.md %}) app for the workshop day: each chapter with only the challenge and the hands-on part.

At the end of the workshop, your message board will look like this:

![The message board with the title at the top, the green New message button and, below it, four yellow cards side by side, each with the message, the author in italics and the Edit and Delete buttons]({{ '/assets/images/mural-de-recados/06/mural-post-it.png' | relative_url }})
{: .ilustracao }

The explanation of each step is in **What happened?**, in the full version of each chapter. Read it at your own pace after the workshop.

Start with chapter 01: the first step is setting up your [codespace]({{ site.baseurl }}{% link glossary.md %}#codespace).
