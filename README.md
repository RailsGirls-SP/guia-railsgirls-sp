# Guia Rails Girls São Paulo

Documentação do workshop Rails Girls São Paulo, publicada com GitHub Pages e o tema [Just the Docs](https://just-the-docs.com).

## Ver o site localmente

Pré-requisito: Ruby 3.3 (veja `.tool-versions`).

```sh
bundle install
bundle exec jekyll serve --livereload
```

Abra http://localhost:4000. As páginas são recarregadas sozinhas quando você salva um arquivo.
