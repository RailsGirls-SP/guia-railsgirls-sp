# Criando uma conta no GitHub

O **GitHub** é um site que guarda projetos de programação e permite trabalhar neles de qualquer lugar. Para entender melhor o que ele é, assista à [introdução a Git e GitHub](https://www.youtube.com/watch?v=UiJ8a8Acvi4) com Rayane Rocha, no Rails Girls São Paulo 2025.

## 1. Comece o cadastro

Acesse [github.com](https://github.com), preencha o seu e-mail no campo **Enter your email** e clique em **Sign up for GitHub**.

![Página inicial do GitHub com o campo de e-mail e o botão Sign up for GitHub destacados]({{ '/assets/images/comece-aqui/github-cadastro-email.png' | relative_url }})

{: .dica }
O site do GitHub está em inglês. Se preferir, peça para o navegador traduzir a página.

<details markdown="1">
<summary>Como traduzir a página no Chrome</summary>

Clique no ícone de tradução, na barra de endereço:

![Barra de endereço do Chrome com o ícone de tradução destacado e a página do GitHub já em português]({{ '/assets/images/comece-aqui/github-traduzir-icone.png' | relative_url }})

E escolha **Portuguese**:

![Janela do Google Tradutor com as opções English e Portuguese, com Portuguese selecionado]({{ '/assets/images/comece-aqui/github-traduzir-portugues.png' | relative_url }})

Preencha o campo **Insira seu e-mail** e clique no botão **Inscreva-se no GitHub**.

</details>

## 2. Preencha os seus dados

Defina:

- uma senha (**Password**);
- um nome de usuária (**Username**), sem espaços nem símbolos especiais. Ele vai aparecer no endereço dos seus projetos;
- o país (**Your Country/Region**): **Brazil**.

Depois, clique em **Create account**.

![Formulário de cadastro do GitHub com os campos Email, Password, Username e Your Country/Region preenchidos, e o botão Create account]({{ '/assets/images/comece-aqui/github-cadastro-formulario.png' | relative_url }})

<details markdown="1">
<summary>Na página traduzida para o português</summary>

Os campos aparecem assim:

- **Senha**;
- **Nome de usuário**;
- **Seu país/região**: **Brasil**.

Depois, clique em **Criar uma conta**.

![Formulário de cadastro do GitHub traduzido para o português, com os campos E-mail, Senha, Nome de usuário e Seu país/região, e o botão Criar uma conta]({{ '/assets/images/comece-aqui/github-cadastro-formulario-ptbr.png' | relative_url }})

</details>

Às vezes o GitHub pede para você resolver um desafio, para confirmar que você não é um robô. Ele tem uma versão com imagens e outra com áudio (dica: a de áudio costuma ser mais fácil).

## 3. Confirme o seu e-mail

O GitHub manda um código para o seu e-mail. Digite o código e clique em **Continue**.

![Tela Confirm your email address do GitHub, com oito caixas para digitar o código e o botão Continue]({{ '/assets/images/comece-aqui/github-cadastro-codigo.png' | relative_url }})

<details markdown="1">
<summary>Na página traduzida para o português</summary>

Digite o código nas caixas abaixo de **Digite o código** e clique em **Continuar**.

![Tela Confirme seu endereço de e-mail do GitHub, traduzida para o português, com oito caixas para digitar o código e o botão Continuar]({{ '/assets/images/comece-aqui/github-cadastro-codigo-ptbr.png' | relative_url }})

</details>

## 4. Faça login

Depois de confirmar o e-mail, o GitHub mostra a tela de login. Preencha **Username or email address** com o seu nome de usuária ou o seu e-mail, e **Password** com a senha que você acabou de criar. Depois, clique em **Sign in**.

![Tela Sign in to GitHub, com os campos Username or email address e Password e o botão Sign in]({{ '/assets/images/comece-aqui/github-login.png' | relative_url }})

<details markdown="1">
<summary>Na página traduzida para o português</summary>

Preencha **Nome de usuário ou endereço de e-mail** e **Senha**, e clique em **Entrar**.

![Tela Faça login no GitHub, traduzida para o português, com os campos Nome de usuário ou endereço de e-mail e Senha e o botão Entrar]({{ '/assets/images/comece-aqui/github-login-ptbr.png' | relative_url }})

</details>

## 5. Confira se deu tudo certo

Depois do login, você chega ao painel do GitHub (**Dashboard**). No topo aparece **Welcome to GitHub**, seguido do seu nome de usuária, e, à esquerda, **No repositories found**: você ainda não tem nenhum projeto.

![Painel do GitHub logo depois do login, com a mensagem Welcome to GitHub seguida do nome de usuária e, à esquerda, No repositories found]({{ '/assets/images/comece-aqui/github-painel.png' | relative_url }})

<details markdown="1">
<summary>Na página traduzida para o português</summary>

No topo aparece **Bem-vindo(a) ao GitHub**, seguido do seu nome de usuária, e, à esquerda, **Nenhum repositório encontrado**.

![Painel do GitHub traduzido para o português, com a mensagem Bem-vindo(a) ao GitHub seguida do nome de usuária e, à esquerda, Nenhum repositório encontrado]({{ '/assets/images/comece-aqui/github-painel-ptbr.png' | relative_url }})

</details>

Pronto, a sua conta está criada! Por enquanto, você não precisa clicar em mais nada nessa página: o seu primeiro repositório vai ser criado no capítulo [Por onde começar?]({{ site.baseurl }}{% link projetos/mural-de-recados/01-por-onde-comecar/index.md %}).
